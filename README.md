# Windows-Icons-Recreation
A recreation of the Windows logo icon based on the [original post by the official Windows Twitter account](https://x.com/Windows/status/1805664279976112195/).

### Cube internal names cheat sheet:

**"WindowsColor"** - *Colorable with Player 1 and Player 2 colors*

**"Windows11"** - *Ignores player colors and always uses the Windows 11 logo's colors*

**"Multicolored"** - *Ditto, but uses the iconic 4 colors of the Windows flag.*


## *This texture pack requires the **"More Icons"** mod by hiimjustin000!*
