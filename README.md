# Windows-Icons-Recreation
A recreation of the Windows logo icon based on the original post by the official Windows Twitter account.

The original post in question:
https://x.com/Windows/status/1805664279976112195/

Cube internal names cheat sheet:

**"WindowsColor"** - *Colorable with Player 1 and Player 2 colors*

**"Windows11"** - *Overwrites colors to use the Windows 11 logo's colors*

**"Multicolored"** - *Overwrites colors to use all 4 colors of the Windows flag.*

## *This texture pack requires the **"More Icons"** mod by hiimjustin000!*
